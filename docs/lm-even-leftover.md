# Even leftover: keep caption even, drop leftover / blend

Generated by `analysis/slider2d/run_lm_even_leftover.py`. CPU only, no Hub,
no GPU, no Music 3 weights. Does not change the live trainer default
(`--lm_target v9` / `--pole_mode hidden`).

Leftover-gate already subtracts unused ê from the **odd** part and still
sits at leftover-sheet `leak_frac` +0.105. The even residual

```
even = ½((h+ − h0) + (h− − h0))
```

is a mix of (1) the shared song / caption that must stay (energy-v4 two
real tracks, leftover-sheet ŝ) and (2) unused leftover / blend junk.
This cell subtracts or holds only (2). It does not delete all of `c`
and is not `t± = h0 ± a`.

A hit is `exam_divergent` True and `leak_frac = cos(d+, d−) < 0`. More
negative is better only if divergent still passes. `leak_frac ≈ −1` +
fail divergent is pair-odd / midpoint Goodhart (banned). `faithful_attrs`
is a data pin. Caption poles: divergent pass, leftover-sheet leak_frac
+0.03 … +0.12.

## What the leftover geometry can see

- **Odd ê / `ê_⊥û`.** Unused leftover in `a`. Leftover-gate and the blend
  guard already decide whether to subtract it. Even-along-ê is a no-op
  on every pair-exam / leftover-sheet field here: leftover-sheet `c` is
  ŝ ⊥ ê, and energy-v4's ê is the track *difference*, orthogonal to the
  track *sum*.
- **Leak-pair even `ê_even`.** The trainer already encodes both leak
  captions. `ê_even = ½((leak+ − h0) + (leak− − h0))` is half of each
  mix/BPM fragment at once — the blend. On energy-v4 that is
  `½ track (p̂+q̂)`. Caption even ŝ is orthogonal to it.
- **Unused overlap floor / blend guard.** The unused floor refuses odd
  subtract when ê restates the tracks. Applying that same floor to
  `ê_even` is a no-op on energy-v4 (the pair that *has* even blend).
  The blend guard admits full `ê_even` subtract (`α = 1`) and the exam
  still fails, so it is too loose for this job.

Full `ê_even` subtract (`α = 1`) reconstructs each pole as
`½ p̂ − ½ q̂` instead of `p̂` / `q̂` and fails divergent (leak_frac
−0.404, not −1). Pair-odd deletes all of `c` and prints −1. Those are
different failures; both are banned.

Leftover-sheet `leak_frac` cannot go negative without shrinking caption
ŝ. That is the banned "delete `c`" continuum. The hit is on the
**divergent** pair, where even blend is the leak-pair sum.

`α = 0.75` and `0.90` of leftover-gated even-blend still pass divergent
on this fixture (`leak_frac` −0.368 / −0.398). `α = 1` fails. The live
flag uses the named half-step `α = 0.5` — enough to cross zero, far
from the fail. Near-track still beats far-track for every `α < 1`;
that is why 0.9 survives and 1.0 does not.

## Live flag (opt-in)

`--lm_target faithful_even_blend --pole_mode hidden` is leftover-gate
on odd plus `--even_blend_scale` (default 0.5) of leak-pair even.
Gender-v4 declares no `leak_*`, so both halves are a no-op and the
teacher is `faithful`. No live listen on this branch.

```bash
python conceptmod/textsliders/train_lm_slider_music3.py \
  --name energy-lm-even-blend \
  --prompts_file conceptmod/textsliders/data/prompts-energy-v4.yaml \
  --lm_target faithful_even_blend --pole_mode hidden \
  --rank 8 --alpha 8 --lr 5e-4 --steps 800 --seed 7 \
  --no-early_stop --endreg_weight 1.0
```

Same card on gender-v4 (`--name gender-lm-even-blend`,
`prompts-gender-v4.yaml`). The listen is the gate. This does not
change the live default.
